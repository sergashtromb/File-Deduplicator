## File deduplicator

Проект для поиска дублей файлов по наименование а так же контрольным суммам хеша

## Требования

- В начале каждого файла писать описание зачем этот файл нужен.
- Использовать логирование
- Использовать пакет конфигурации для настройки

## Суть работы

Запускается эта утилита через консоль.
Утилита принимает параметры:

	1. Параметр/флаг -r  использовать ли рекурсивный поиск
	
	2. Параметр/флаг -s сохранять ли результат в файл json
	
	3. Параметр - Path - с которого начнется поиск дублей

Вид команды:

```
file_dd [-r] [-s] Path
```

Утилита получает на вход параметры. Далее запускает поиск если включен флаг рекурсии то ищет в подчиненных папках и файлах. 

Модель найденного файла содержит имя, хеш и путь.
Модель дубля в которой указывается id и массив ссылок к структуре найденного файла.
Есть общий массивы который содержит эти модели.
Есть общий массив который содержит в целом найденные не пустые файлы.

Запускается поиск, если в массиве файлов находит папку запускает в отдельной горутине еще один поиск по этой папке. При поиске игнорирует пустые файлы.

Результат  возвращает в виде json массива с нашей моделью.

## Структура

- file_deduplicator
	- [[domain]] - пакет в котором объявляются все модели а также реализации интерфейсов
	- [[logger]] - пакет для работы с механизмом логированием, его настройка и инициализация
	- [[config]] - пакет для работы с механизмом конфигурации программы ее чтением и записью
	- initial
		- stores - пакет всех хранилищ
			- duplicate_store - хранилище для работы с общем массивом дублей для записи, чтения, а также поиска уже найденных дублей
			- file_store - хранилище для работы с общем массивом всех найденных не пустых файлов
		- walker_manager - пакет для контроля и запуска горутин поиска, следит за количеством одновременно запущенных горутин.
		- search_agent - пакет для поиска файлов по имени и хешу, зависит от stores
		- report - пакет для отчета о найденных файлах
